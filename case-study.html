GRADUATION PROJECT

Lost in Egypt

A smart AI-powered tourism platform built with Flutter to help people explore Egypt with maps, recommendations, landmark understanding, community features, and travel assistance in one app.

Back to Portfolio

01 — THE PROBLEM

Traveling in Egypt often requires users to rely on multiple apps and systems for maps, recommendations, translation, tour information, guides, and planning. Lost in Egypt was designed to bring these essential travel services together into a single, more accessible platform.

02 — THE IDEA

The project idea was to create a smart tourism companion that helps users discover places, understand landmarks, receive personalized recommendations, and navigate the country with more confidence through mobile technology and AI-powered support.

03 — THE SOLUTION

Lost in Egypt combines Flutter-based mobile interfaces with Firebase backend services, Google Maps, AI-powered image and text understanding, multilingual support, recommendations, tour and guide features, and user community tools into one tourism platform.

04 — HOW IT WORKS

User ↓ Interface ↓ Flutter App ↓ AI / ML ↓ Firebase / Maps ↓ Travel Result

The project follows a travel workflow in which users interact with the app, receive contextual guidance, and access map, AI, and backend services to support decisions and trip planning.

AI / ML

AI is used to help users understand places and information faster. The app includes camera and image support, Google ML Kit text recognition, ML Kit translation, and Gemini AI for contextual understanding and travel assistance. These capabilities help users interpret signs, landmarks, and written travel information without needing to search separately.

  • AI-powered image and landmark understanding
  • Text extraction from images using ML Kit
  • Translation support for Arabic and English content
  • Gemini-powered contextual guidance for travel questions
  • Voice input/output support for easier interaction while on the move

UI / UX

Research ↓ User Flow ↓ Wireframes ↓ High-Fidelity Design ↓ Prototype ↓ Final Interface

The project emphasizes a responsive, mobile-first travel experience with Arabic and English support, modern UI design, and a focus on usability for tourists and local users.

ARCHITECTURE

Flutter App → Firebase Auth → Firestore & Realtime DB → Gemini / ML Kit → Maps & Notifications

The system integrates the mobile frontend with Firebase services, Google Maps, AI features, and community travel data.

SECURITY & PRIVACY

Firebase Authentication is used to manage secure user access with email/password, Google Sign-In, and Facebook login support. User-specific data is linked to Firebase services, and backend logic can be handled in Cloud Functions to keep sensitive operations off the client side.

CHALLENGES & SOLUTIONS

The main challenge was consolidating the many travel tasks users typically handle in separate apps—navigation, recommendations, translation, community interaction, guide support, and booking—into one platform. The solution was to combine maps, AI, Firebase, and user-centered design into a single travel workflow.
